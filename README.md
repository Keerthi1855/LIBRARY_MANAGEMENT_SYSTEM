# Library Management System (LMS)

## Overview

A menu-driven Library Management System developed in C using a Singly Linked List and modular programming approach. The application allows librarians to efficiently manage book records, issue and return transactions and maintain persistent storage through file handling.

## Features

* Add new book records
* Update book details
* Delete books by ID or title
* Search books by ID, title, or author
* Display all available books
* Issue books to users
* Return issued books
* Track issued book records
* Automatic issue and due date management
* Save records to files
* Load records automatically at startup

## Technologies Used

* C Programming
* Data Structures (Singly Linked List)
* Dynamic Memory Allocation
* File Handling
* Makefile
* GCC
* Linux
